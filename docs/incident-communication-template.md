# Incident Communication Template

Use this template for stakeholder-facing incident updates. Keep updates concise and factual.

Title: [Incident] short-description (severity)

1) Summary
- What happened (1–2 sentences)
- When it started (timestamp)

2) Impact
- Who/what is affected (customers, services)
- Scope and estimated user impact

3) Current status
- What the team is doing now
- Short term mitigation (if any)

4) Next steps
- Immediate actions planned and owners
- ETA for next update

5) Contact
- Incident lead: @handle
- Support Owner: @handle
- Channel: #incident-channel

Post-incident
- Link to postmortem: (URL)
- Primary root cause (summary)
- Action items and owners

Share cadence
- Initial acknowledgement: within 15 minutes of detection
- Status updates: every 30–60 minutes (adjust by severity)
- Post-incident summary: within 48 hours
